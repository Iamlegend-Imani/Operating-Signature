# Operating Signature — V1

**You are not one type. You are a pattern.**

Operating Signature is an exploratory multidimensional assessment that maps how a person naturally tends to think, build, decide, communicate, connect, and create.

Rather than assigning one fixed archetype, V1 scores ten operating dimensions independently and turns the strongest combination into a **Primary Pattern**.

## Operating dimensions

1. Systems Thinker
2. Builder
3. Analyst
4. Strategist
5. Synthesizer
6. Innovator
7. Operator
8. Translator
9. Connector
10. Explorer

## V1 experience

- 30 scenario prompts
- 10 independent 0–100 expression scores
- top three dominant operating signals
- generated Primary Pattern such as **System Builder**
- living radar / signature map
- full composition score view
- strengths and growth-edge interpretation
- downloadable share card
- responsive single-page experience
- no account, database, cookies, analytics, or backend required

## Methodology note

This is an **exploratory beta, not yet a validated psychometric instrument**. The numbers are internal expression scores, not population percentiles, diagnostic measures, or scientifically validated norms.

Before making stronger claims, later versions should be tested for construct validity, item quality, reliability, test-retest stability, measurement bias/invariance, and score calibration on a sufficiently large sample.

## Product architecture

**Operating Archetypes → Operating Signature → Primary Pattern**

Future versions can add contextual maps (work, relationships, creativity, stress), longitudinal change, team composition, role fit, and population-calibrated norms without changing the core thesis.
